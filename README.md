# Balloon Store

Интернет-магазин воздушных шаров для Москвы и Московской области.

Сейчас завершён первый этап: подготовлена техническая основа проекта. Каталог,
база данных, корзина, оформление заказа и административная панель будут
добавляться отдельными этапами после проверки каждого предыдущего этапа.

## Технологии

- Next.js с App Router и TypeScript
- Tailwind CSS
- PostgreSQL и Supabase
- Supabase Auth и Supabase Storage
- React Hook Form и Zod
- Zustand
- ESLint

Проект использует официальный клиент Supabase. Prisma и другие ORM для
PostgreSQL не подключаются.

## Требования

- Node.js версии 22.13 или новее
- npm
- проект Supabase для этапов, связанных с базой и авторизацией

## Первый запуск

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Создайте локальный файл настроек на основе `.env.example`:

   ```bash
   copy .env.example .env.local
   ```

   На macOS или Linux используйте:

   ```bash
   cp .env.example .env.local
   ```

3. Впишите в `.env.local` значения из панели Supabase. Секретный служебный
   ключ должен оставаться только в локальном или серверном окружении.

4. Запустите проект:

   ```bash
   npm run dev
   ```

5. Откройте [http://localhost:3000](http://localhost:3000).

До подключения Supabase сайт показывает временный экран подготовки. Это
ожидаемое поведение первого этапа.

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `NEXT_PUBLIC_SUPABASE_URL` | Адрес проекта Supabase |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | Публичный ключ Supabase |
| `NEXT_PUBLIC_SITE_URL` | Адрес сайта, локально `http://localhost:3000` |
| `SUPABASE_SERVICE_ROLE_KEY` | Служебный серверный ключ; запрещено передавать в браузер |

`.env.local` не добавляется в Git. В репозитории хранится только безопасный
пример `.env.example`.

## Проверка проекта

```bash
npm run lint
npm run typecheck
npm test
```

Команда `npm test` также выполняет production-сборку.

## Текущая структура

```text
app/                    страницы и общие макеты App Router
components/             общие интерфейсные компоненты
features/               функциональные модули магазина
lib/environment.ts      проверка переменных окружения
lib/money.ts            безопасная работа с ценами в копейках
lib/supabase/            браузерный и серверный клиенты Supabase
public/                  статические файлы
tests/                   автоматические проверки
.openai/hosting.json    конфигурация публикации сайта
```

В `features` уже зафиксированы базовые контракты корзины, оплаты и доставки.
Сами интеграции оплаты и доставки не входят в минимальную первую версию.

## Правила разработки

- Каждый крупный этап завершается запуском проекта, линтером, проверкой типов,
  тестами и production-сборкой.
- Следующий этап начинается только после успешного завершения предыдущего.
- Цены хранятся целым числом копеек и форматируются как российские рубли.
- Клиентская часть не считается доверенным источником цены или наличия.
- Секретные ключи не записываются в исходный код.
